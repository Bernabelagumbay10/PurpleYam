# PurpleYum Landing Page

A premium landing page for a cake ordering app with online payment and pick-up options.

## Features

- Modern minimalist design with purple gradient accents
- Animated hero, feature cards, step flow, showcase, testimonials, and CTA
- Responsive layout with clean spacing and glassmorphism styling
- Built using plain HTML, CSS, and JavaScript

## Files

- `index.html` — Main HTML file
- `styles.css` — All styles
- `script.js` — JavaScript for interactivity and animations
- `public/` — Images and assets

## How to View

Open `index.html` in a web browser or serve the directory with a local server.

## Notes

The hero section uses a floating app mockup and polished CTA layout to match the reference design.
Focuses on online ordering, secure payments, and convenient pick-up.
